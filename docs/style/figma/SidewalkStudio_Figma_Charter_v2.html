Color Tokens

Two atmospheric states built from one coherent token architecture. Shared structural tokens hold constants; theme-specific tokens override surfaces, text, accents. The dominant accent (blue / violet) provides UI structure; the sun accent (amber / orange) provides CTA and warmth; green is a persistent identity accent in both themes.

04

Radius & Border Rules

Subtle, discreet rounding. The system reads as structured and civic, not soft or consumer-app. radius-sm for micro-elements, radius-md for cards and inputs, radius-lg only for large overlays. No blob UI.

Radius Scale

TokenValueApplied to
--sw-radius-none0pxTable rows, inline dividers, transit lines
--sw-radius-sm4pxLegendChip, badge, tag, code block, small button
--sw-radius-md8pxProjectCard, WritingCard, Panel, Input, standard Button
--sw-radius-lg16pxModal overlay, large feature panel, MetricStrip ends
--sw-radius-xl24pxSunAnchor component only — never reused elsewhere
--sw-radius-full9999pxAvatar, dot indicator, circular toggle only

Border Rules

ContextRule
Card default1px solid --sw-border · radius-md
Card accent1px solid --sw-border + bottom 2px solid --sw-accent-dominant
Panel elevated1px solid --sw-border · radius-md · shadow-sm
Input default1px solid --sw-border · radius-md
Input focus2px solid --sw-border-focus (no outline offset)
LegendChip1px solid --sw-border · border-left 3px solid [accent] · radius-sm
Section divider1px solid --sw-border · no radius · width 100%
Table row1px solid --sw-border bottom only · radius-none
Transit line2px solid [accent-color] left · radius-none · left-padding 20px
Focus ring2px solid --sw-border-focus · offset 2px · radius matches element
Forbidden: radius > 16px on any card or panel. Full-radius on rectangular content blocks. Mixing radius values on the same component. Shadows on the sun component — glow only via box-shadow blur, no offset.

Signature Components

Eleven named components. Each has a single responsibility. Naming is final — use these exact names in Figma, in Vue components, and in class/token references.

SunAnchor

Atmospheric signature component. A radial gradient circle that anchors the emotional temperature of the page. Lives in the header, positioned absolutely. Its position, size, and gradient respond to the active theme. Motion is a slow, looping drift — interrupted by a position transition on theme change.

Homepage Structure

Eight sections. Density descends from high to low. The emotional peak is the hero. The credibility anchor is the metric strip immediately below. Pacing opens up from section 3 onward.

Desktop Layout — Section Order

00 Header — always present · not counted as section —

SunAnchor + wordmark + ThemeToggle + NavTabs. Background: --sw-header-bg. Position: sticky on scroll.

Height ~120px desktop · 72px mobile. Stacks to icon + hamburger on mobile.

01 Hero High — Peak visual moment

Full-width, min-height 80vh. SunAnchor bleed from the header into this section. Display XL headline in Fraunces italic. One body/large descriptor. One primary CTA (Projects) + one ghost CTA (Writing). No image — typography and atmosphere carry this.

Columns: 8/12 centered · py: 128px · Background: --sw-bg-base (seamless from header)

02 MetricStrip Low — Credibility band

5–6 metrics. Immediate credibility signal. Full 12-column width. No section padding — flush to section above and below.

12/12 · py: 0 (internal padding 20px) · Metrics: years exp, sites, Lighthouse, RGPD score, CMS count

03 What I care about Medium — Identity anchoring

3-column grid. SectionIntro (Fraunces headline) + 3 equal blocks: Engineering / Privacy / Cities. Short prose paragraphs (no bullet lists). No cards — plain type with a thin left accent border per column.

4/12 × 3 · py: 96px · Left border: 3px solid [accent per column]

04 Selected Projects High — Portfolio evidence

SectionIntro + 3–4 ProjectCards in a grid. "All projects →" ghost link at bottom right. Cards have a 2px accent bottom strip in the project category color.

4/12 × 3 (or 6+3+3) · py: 96px · Max 4 cards on home

05 Writing Teaser Medium — Content credibility

SectionIntro (tight) + 3 WritingCards stacked. Full-width list, no grid. "All writing →" link at end.

8/12 centered · py: 80px

06 LocalBlock — Civic & Situated Low — Personality layer

Integrated local section. NOT a sidebar or aside. SectionIntro + 3 TransitLines (mobility / orgs / culture) + LocalFootnote. Background: --sw-bg-grid for visual separation.

4/12 × 3 · py: 96px · bg: --sw-bg-grid

07 Contact Low — Restrained close

Minimal. SectionIntro + email link (large, styled as display/l) + GitHub / LinkedIn / Mastodon social links as text links. No form in v0. No heavy card layout.

6/12 centered · py: 96px

CSS implementation alignment: All --sw-* tokens map directly to Tailwind v4 CSS custom properties in resources/css/app.css. The Tailwind config extends the default theme with these tokens under the colors.*, spacing.*, borderRadius.*, and fontFamily.* keys. The Vue component for each Figma component lives at resources/js/components/[ComponentName].vue.
