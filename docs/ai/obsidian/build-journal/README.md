# Obsidian Build Journal Mirror

Use this folder for repo-safe summaries exported from the private Obsidian vault.

## What belongs here

- short build logs worth keeping with the codebase
- decision summaries that explain why a change landed
- handoff notes that future Codex sessions should find without opening the private vault

## Naming

- `YYYY-MM-DD-build-log.md` for day-level notes
- `YYYY-MM-DD-release-note.md` for release prep notes
- Add the spec ID in the title or first lines when the note maps to a tracked feature

## Promotion rule

If a note becomes a real architecture decision, move the durable version into `docs/architecture/decisions/`.
