# Architecture Decisions

Use this folder for durable decisions that graduate from temporary build notes or Obsidian exploration.

## Rule

- Keep one Markdown file per decision when the decision changes the app, content model, consent model, or SEO behavior.
- Prefer concise ADR-style notes with context, decision, consequences, and any deferred tradeoffs.
- Raw working notes stay outside this folder until the decision is stable enough to matter to the repo.
- Start from `.specify/templates/decision-template.md` instead of inventing a new format each time.
