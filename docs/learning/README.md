# Learning Notes

This folder exists to capture implementation lessons in plain language while the project grows.

## Why this exists

- to keep technical learnings close to the codebase
- to capture bugs, constraints, and infrastructure changes while they are still fresh
- to make future explanations easier in interviews, debriefs, and self-review

## What belongs here

- implementation notes from completed feature passes
- recurring bugs and how they were resolved
- local environment and tooling quirks
- architectural decisions worth being able to explain clearly
- frontend notes for Vue, Inertia, Laravel, content architecture, and validation flow

## What does not belong here

- speculative product plans with no implementation
- duplicate architecture docs
- private or secret operational data

## Suggested note structure

```md
# Title

## Context

## Problem or friction

## What changed

## What I learned

## Tradeoffs

## Follow-up
```
