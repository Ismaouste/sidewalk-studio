# Content Model

## Shared contract

Every Markdown document must define:

- `title`
- `slug`
- `summary`
- `status`
- `published_at`
- `updated_at`
- `tags`
- `seo_title`
- `seo_description`

## Case-study-only fields

- `client`
- `role`
- `stack`
- `outcomes`

## Runtime shaping

The PHP repository adds:

- rendered HTML
- excerpt
- reading time
- public URL
